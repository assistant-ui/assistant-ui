Guides are task-oriented walkthroughs for building specific features on top of assistant-ui. They sit between the [Primitives](/docs/primitives) (low-level building blocks) and [Components](/elements/thread) (pre-styled installs). Pick a guide when you know what you want to build and need the recommended pattern.

## Composer

Extend the message input with file attachments, mentions, slash commands, input history, quoting, and dictation, or bring your own input.

<Cards>
  <Card title="Attachments" href="/docs/guides/attachments">
    Let users attach files, images, and documents to messages. Covers upload adapters, validation, and the typed `attachmentAddError` event.
  </Card>
  <Card title="Mentions" href="/docs/guides/mentions">
    `@`-style triggers that insert directives into the composer. Sync and async search patterns.
  </Card>
  <Card title="Slash Commands" href="/docs/guides/slash-commands">
    `/`-style commands with arguments, async loading, and combining with mentions.
  </Card>
  <Card title="Input History" href="/docs/guides/input-history">
    Recall earlier messages with ArrowUp and ArrowDown in an empty composer, like a shell prompt, with `unstable_useComposerInputHistory`.
  </Card>
  <Card title="Headless Composer Input" href="/docs/guides/headless-composer-input">
    Bring your own editor or textarea and keep composer state and send gating through `unstable_useComposerInput`.
  </Card>
  <Card title="Quoting" href="/docs/guides/quoting">
    Selection toolbar, programmatic `setQuote`, and forwarding quote context to the LLM.
  </Card>
</Cards>
