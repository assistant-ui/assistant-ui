This page sets up a working ADK chat in four steps. It assumes you have already installed the package and have ADK ready on the server side; if not, start at [overview](/docs/runtimes/google-adk/overview).

<Steps>
<Step>

### Create a backend API endpoint

Use `createAdkApiRoute` to create an API route.
For React Native and Ink, host this route in a separate backend project and
point the client runtime at its absolute URL.

```ts title="app/api/chat/route.ts"
import { createAdkApiRoute } from "@assistant-ui/react-google-adk/server";
import { InMemoryRunner, LlmAgent } from "@google/adk";
import { requireUser } from "@/lib/auth";

const agent = new LlmAgent({
  name: "my_agent",
  model: "gemini-3.8-flash",
  instruction: "You are a helpful assistant.",
});

const runner = new InMemoryRunner({ agent, appName: "my-app" });

export const POST = createAdkApiRoute({
  runner,
  userId: async (req) => (await requireUser(req)).id,
  sessionId: (_req, clientSessionId) => {
    if (!clientSessionId) throw new Error("Missing ADK session ID");
    return clientSessionId;
  },
});
```

`createAdkStream` sends the initialized assistant-ui thread ID as
`clientSessionId`. Resolve `userId` from your authentication system before
accepting it: the client-sent ID selects a conversation, but does not authorize
access to it. Static user and session IDs are suitable only for a local,
single-user development route.

</Step>
<Step>

### Set up the client runtime

Use `createAdkStream` to connect to your API route. It parses the SSE stream for you:

<PlatformTabs>
<Tab value="React">

```tsx title="components/MyAssistant.tsx"
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import {
  useAdkRuntime,
  createAdkStream,
} from "@assistant-ui/react-google-adk";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export function MyAssistant() {
  const runtime = useAdkRuntime({
    stream: createAdkStream({ api: "/api/chat" }),
  });
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

</Tab>
<Tab value="React Native">

```tsx title="components/MyAssistant.tsx"

import {
  useAdkRuntime,
  createAdkStream,

    stream: createAdkStream({ api: `${API_URL}/api/chat` }),
  });
  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <Thread />
    </AssistantRuntimeProvider>
  );
}
```

## Adding adapters

Attachment, speech, dictation, voice, and feedback adapters go in the `adapters` option. See [adapters](/docs/runtimes/concepts/adapters):

```tsx
const runtime = useAdkRuntime({
  stream: createAdkStream({ api: "/api/chat" }),
  adapters: { attachments, speech, feedback },
});
```

For multi-thread, see [threads](/docs/runtimes/concepts/threads).
