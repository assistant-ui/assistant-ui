assistant-ui is a library for the chat interface of an AI app. It gives you the thread and the composer as components you own and can edit, and a runtime that handles streaming, tool calls, attachments and thread history against the model or agent backend you already use. [Architecture](/docs/architecture) shows how the parts fit together, and [Concepts](/docs/concepts/runtime) explains each one.
