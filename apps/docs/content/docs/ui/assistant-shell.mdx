A complete app shell for chat applications: a collapsible sidebar with the thread list, a header with a sidebar toggle and the active thread title, and your chat content in the main area. On mobile, the sidebar becomes a slide-out drawer.

## Branding

The sidebar and the mobile drawer show a logo and title, defaulting to the assistant-ui mark and wordmark. Pass `logo` and `title` to brand the shell, or `null` to render either without a replacement:

```tsx
<AssistantShell logo={<MyLogo />} title="My App">
  <Thread />
</AssistantShell>
```

## Header actions

The right side of the header is an empty slot reserved for your app's own controls: an account menu, a share button, a settings toggle, a model picker. Nothing renders there by default. Fill it with `headerActions`, which accepts any `ReactNode` and lays multiple children out in a right-aligned row:

```tsx title="/app/assistant.tsx"
import { AssistantShell } from "@/components/assistant-ui/assistant-shell";
import { TooltipIconButton } from "@/components/assistant-ui/tooltip-icon-button";
import { Thread } from "@/components/assistant-ui/thread";
import { SettingsIcon, Share2Icon } from "lucide-react";

export const Assistant = () => {
  return (
    <AssistantShell
      headerActions={
        <>
          <TooltipIconButton tooltip="Share" onClick={() => {/* share the thread */}}>
            <Share2Icon />
          </TooltipIconButton>
          <TooltipIconButton tooltip="Settings" onClick={() => {/* open settings */}}>
            <SettingsIcon />
          </TooltipIconButton>
        </>
      }
    >
      <Thread />
    </AssistantShell>
  );
};
```

`TooltipIconButton` ships with `assistant-shell` as a registry dependency; any element works. In a [custom composition](#custom-composition), the same slot is `AssistantShellHeader`'s `children`.

## Sidebar footer

The bottom of the sidebar is a second empty slot, the conventional home for an account menu. Fill it with `sidebarFooter`; the same content also renders at the bottom of the mobile drawer.

For the common case — an avatar button that collapses to just the avatar in the icon rail — pair the slot with `AssistantShellFooterItem`. It renders an icon, a label, and an optional description and trailing element, hides everything but the icon when the sidebar collapses (with the label as a tooltip), and works as a menu trigger:

```tsx title="/app/assistant.tsx"
import {
  AssistantShell,
  AssistantShellFooterItem,
} from "@/components/assistant-ui/assistant-shell";
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu";
import { Thread } from "@/components/assistant-ui/thread";

const AccountMenu = () => {
  return (
    <DropdownMenu>
      <DropdownMenuTrigger
        render={
          <AssistantShellFooterItem
            icon={
              <Avatar>
                <AvatarImage src="/avatar.png" alt="" />
                <AvatarFallback>BS</AvatarFallback>
              </Avatar>
            }
            label="Bassim Shahidy"
            description="Personal account"
          />
        }
      />
      <DropdownMenuContent side="top" align="start" className="w-56">
        <DropdownMenuItem>Settings</DropdownMenuItem>
        <DropdownMenuItem>Sign out</DropdownMenuItem>
      </DropdownMenuContent>
    </DropdownMenu>
  );
};

export const Assistant = () => {
  return (
    <AssistantShell sidebarFooter={<AccountMenu />}>
      <Thread />
    </AssistantShell>
  );
};
```

The slot accepts any `ReactNode` — a plain settings link or an upgrade banner works just as well. In a [custom composition](#custom-composition), the same slot is `AssistantShellSidebar`'s `footer` prop.

## Collapse and persistence

On desktop, the sidebar toggles between full width and a narrow icon rail. Three ways to toggle:

- The panel button in the header
- <kbd>Cmd</kbd>+<kbd>B</kbd> (macOS) / <kbd>Ctrl</kbd>+<kbd>B</kbd>
- `toggle()` from [`useAssistantShell`](#useassistantshell) in your own components

Below the `md` breakpoint the sidebar is replaced by a slide-out drawer, opened from the menu button in the header.

The collapsed state persists to the `assistant-shell-collapsed` cookie (values `"true"` / `"false"`). In a server-rendered app, read the cookie on the server and pass it back as `defaultCollapsed` so the sidebar restores without a flash:

```tsx title="/app/page.tsx"
import { cookies } from "next/headers";
import { Assistant } from "./assistant";

export default async function Page() {
  const cookieStore = await cookies();
  const collapsed = cookieStore.get("assistant-shell-collapsed")?.value === "true";
  return <Assistant defaultCollapsed={collapsed} />;
}
```

Without this, the sidebar renders expanded on the server and snaps to the persisted state after hydration.

## Custom composition

`AssistantShell` is a thin arrangement of exported parts. Compose them directly when you need a custom header, extra sidebar content, or a different main layout:

```tsx title="/app/assistant.tsx"
import {
  AssistantShellHeader,
  AssistantShellMain,
  AssistantShellRoot,
  AssistantShellSidebar,
} from "@/components/assistant-ui/assistant-shell";
import { Thread } from "@/components/assistant-ui/thread";

export const Assistant = () => {
  return (
    <AssistantShellRoot>
      {/* desktop sidebar: logo, title, new thread, thread list, footer */}
      <AssistantShellSidebar />
      {/* rounded main surface beside the sidebar */}
      <AssistantShellMain>
        {/* mobile drawer trigger, sidebar toggle, thread title, actions */}
        <AssistantShellHeader>{/* header actions */}</AssistantShellHeader>
        <main className="flex-1 overflow-hidden">
          <Thread />
        </main>
      </AssistantShellMain>
    </AssistantShellRoot>
  );
};
```

`AssistantShellRoot` owns the collapse state, so every part works the same inside a custom arrangement.

For a fully custom header, skip `AssistantShellHeader` and build your own from the same atoms it uses — `AssistantShellSidebarToggle`, `AssistantShellThreadTitle`, and `AssistantShellMobileSidebar`:

```tsx
<AssistantShellMain>
  <header className="flex h-12 shrink-0 items-center gap-2 px-4">
    <AssistantShellMobileSidebar />
    <AssistantShellSidebarToggle />
    <ModelPicker />
    <ShareButton className="ml-auto" />
  </header>
  <main className="flex-1 overflow-hidden">
    <Thread />
  </main>
</AssistantShellMain>
```

### AssistantShellThreadTitle

Displays the title of the active thread, falling back to "New Chat". Rendered automatically by `AssistantShellHeader`. Takes no props.

## Styling

Every element carries a `data-slot="aui_shell-*"` attribute for CSS targeting without editing the component:

| Slot                        | Element                                |
| --------------------------- | -------------------------------------- |
| `aui_shell-root`            | Outer layout container                 |
| `aui_shell-sidebar-wrapper` | Desktop-only wrapper around the sidebar |
| `aui_shell-sidebar`         | Desktop sidebar                        |
| `aui_shell-sidebar-header`  | Logo and title row in the sidebar      |
| `aui_shell-logo`            | Logo container                         |
| `aui_shell-sidebar-title`   | Sidebar title text                     |
| `aui_shell-sidebar-new`     | New Thread row pinned above the list   |
| `aui_shell-sidebar-scroll`  | Scrollable thread list area            |
| `aui_shell-sidebar-footer`  | Footer container below the thread list |
| `aui_shell-main-wrapper`    | Padding wrapper around the main surface |
| `aui_shell-main`            | Main content surface                   |
| `aui_shell-content`         | Content area below the header          |
| `aui_shell-header`          | Top bar                                |
| `aui_shell-sidebar-toggle`  | Collapse toggle button                 |
| `aui_shell-thread-title`    | Active thread title                    |
| `aui_shell-header-actions`  | Right-aligned header actions container |
| `aui_shell-mobile-trigger`  | Mobile drawer menu button              |
| `aui_shell-mobile-header`   | Logo and title row in the drawer       |
| `aui_shell-mobile-content`  | Thread list container in the drawer    |
| `aui_shell-mobile-footer`   | Footer container in the drawer         |
| `aui_shell-footer-item`     | Footer item button                     |
| `aui_shell-footer-item-icon` | Footer item icon container            |
| `aui_shell-footer-item-text` | Footer item label and description     |
| `aui_shell-footer-item-trailing` | Footer item trailing element      |

```css
[data-slot="aui_shell-sidebar"] {
  /* custom sidebar styles */
}
```
