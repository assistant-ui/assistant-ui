`ThreadWelcomeSuggestions` renders starter prompts for an empty thread. Grouped entries render as a pill row that opens a composer-coupled picker panel; flat entries render as an always-open vertical list. A second layout, the [stacked variant](#stacked-layout), keeps every group visible as a vertical list. Place either next to any composer; no wrapper elements or thread layout changes are required.

<Callout type="info">
  For runtime-generated prompts that appear after an assistant response, use
  [Follow-Up Suggestions](/docs/ui/follow-up-suggestions) instead.
</Callout>

### Add `welcome-suggestions`

<InstallCommand shadcn={["welcome-suggestions"]} />

This adds a `/components/assistant-ui/welcome-suggestions.tsx` file to your project.

  </Step>

### Provide suggestions

Pass entries through the `suggestions` prop. An entry with a `suggestions` array is a group; without one it is a flat item. When the prop is omitted, the component reads the static welcome prompts configured with `Suggestions(...)`. Dynamic follow-up prompts from `thread.suggestions` are never rendered here.

```tsx title="/components/assistant-ui/thread.tsx"
import {
  ThreadWelcomeSuggestions,
  type SuggestionEntry,
} from "@/components/assistant-ui/welcome-suggestions";

const WELCOME_SUGGESTIONS: SuggestionEntry[] = [
  {
    label: "Weather",
    icon: <CloudSunIcon />,
    suggestions: [
      {
        label: "in San Francisco",
        prompt: "What's the weather in San Francisco?",
      },
      { label: "in Tokyo", prompt: "What's the weather in Tokyo?" },
    ],
  },
  { label: "Compare React and Vue" }, // flat item; label doubles as prompt
];
```

  </Step>
  <Step>

### Render next to the composer

```tsx title="/components/assistant-ui/thread.tsx" {4}
<ThreadPrimitive.ViewportFooter>
```

## Behavior

Selecting a suggestion goes through `ThreadPrimitive.Suggestion`: by default (`send`) it sends the prompt immediately; with `send={false}` it places the prompt in the composer for editing. Clicking an item and pressing <kbd>Enter</kbd> on the highlighted item are the same action.

While a group panel is open, the composer keeps focus and drives the panel:

| Key                          | Action                                                                   |
| ---------------------------- | ------------------------------------------------------------------------ |
| <kbd>↑</kbd> / <kbd>↓</kbd>  | Move the highlight and live-preview the prompt in the composer            |
| <kbd>Enter</kbd>             | Select the highlighted item (plain composer submit when nothing is highlighted) |
| <kbd>Esc</kbd>               | Close the panel and restore the composer text from before it opened       |
| <kbd>Tab</kbd>               | Close the panel and move focus on; the previewed prompt stays in the composer |
| Characters                   | Type into the composer; the panel dismisses                               |

Previewing writes over the composer, but a draft is never silently lost: <kbd>Esc</kbd> (or the close button) is cancel and puts the pre-open draft back, while <kbd>Tab</kbd> and selection accept what the picker wrote.

In the pill row, pills are tab stops: <kbd>←</kbd>/<kbd>→</kbd> move focus and <kbd>↓</kbd> or <kbd>Enter</kbd> opens a group. In the flat list, items are tab stops navigated with <kbd>↑</kbd>/<kbd>↓</kbd>.

## Props

- `suggestions`: the entries to render; falls back to the static `Suggestions(...)` scope. Pass the prop for grouped entries.
- `send`: default `true`. Whether selecting an item sends the prompt immediately or places it in the composer.

## Stacked layout

`WelcomeSuggestionsStack` renders everything as one vertical list, ChatGPT-style. Top-level rows are always visible and never intercept typing; clicking a group swaps its items in place (no header). The sub-level behaves exactly like the picker: arrows preview into the composer, and <kbd>Esc</kbd>, editing the text, or clicking outside return to the top level.

```tsx
<WelcomeSuggestionsRoot suggestions={WELCOME_SUGGESTIONS}>
  <WelcomeSuggestionsStack />
</WelcomeSuggestionsRoot>
```

The top level is a single tab stop with one highlight shared by hover and the arrow keys:

| Key                             | Action                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------- |
| <kbd>↓</kbd> / <kbd>↑</kbd>     | Move the highlight                                                               |
| <kbd>→</kbd> / <kbd>Enter</kbd> | Open the highlighted group (<kbd>Enter</kbd> on a flat row sends it)             |
| <kbd>Esc</kbd> (inside a group) | Return to the list with that group's row highlighted; arrow navigation continues |

### Styling

Stacked rows share the picker's defaults: comfortable density, separators, and no group indicator (try the toggles in the demo above):

- `density`: `"comfortable"` (default) or `"compact"` for tighter rows.
- `separators`: default `true`; hairline dividers between rows, hidden around the highlighted row.
- `indicator`: default `"none"`; `"chevron"` adds a trailing chevron to group rows (flips in RTL).
- `className`: merged onto the listbox container.

```tsx
<WelcomeSuggestionsStack density="compact" separators={false} />
```

The sub-level rows inherit `density` and `separators` from the stack. The stack mirrors `indicator`, and any explicitly set `density` or `separators`, as `data-*` attributes on `[data-slot="aui_thread-welcome-stack"]` for CSS overrides. `WelcomeSuggestionsPicker` accepts `density` and `separators` too, so the pills layout's panel can share the same look.

## Custom composition

The default export composes exported subcomponents you can arrange yourself: `WelcomeSuggestionsRoot`, `WelcomeSuggestionsPills`, `WelcomeSuggestionsPicker`, `WelcomeSuggestionsPickerItem`, `WelcomeSuggestionsList`, `WelcomeSuggestionsStack`, and the `useWelcomeSuggestions` context hook.

```tsx
<WelcomeSuggestionsRoot suggestions={WELCOME_SUGGESTIONS}>
  <WelcomeSuggestionsPills />
  <WelcomeSuggestionsPicker />
</WelcomeSuggestionsRoot>
```

When composing your own picker rows, `WelcomeSuggestionsPickerItem` accepts the same `density` and `separators` options as the stack. `WelcomeSuggestionsList` renders flat entries only; use `WelcomeSuggestionsStack` when groups are present.
