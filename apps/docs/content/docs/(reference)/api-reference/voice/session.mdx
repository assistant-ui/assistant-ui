### GeminiLiveVoiceAdapter

Connects browser microphone audio directly to the Gemini Live API over a
WebSocket. Configure the model, voice, and transcription on the server
through the ephemeral token's connection constraints. Each connection starts
a new conversation; existing thread history and assistant-ui tools are not
sent to the voice model, and sessions end when Google's session limit is
reached.

<ParametersTable {...GeminiLiveVoiceAdapter} />

### OpenAIRealtimeVoiceAdapter

Connects browser microphone audio directly to OpenAI Realtime over WebRTC.
Configure audio output, input transcription, and automatic turn detection on
the server. Each connection starts a new conversation; existing thread history
and assistant-ui tools are not sent to the voice model.
