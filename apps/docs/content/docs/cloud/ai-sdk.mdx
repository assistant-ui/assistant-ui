## What changed

`@assistant-ui/cloud-ai-sdk` and its `useCloudChat` hook are no longer the recommended way to put an AI SDK app on the cloud. Everything the hook did on the wire lives in the `assistant-cloud` package, which every integration now shares: thread and message storage, the `ai-sdk/v6` message format, run and engagement reporting, and thread titles. The package stays published and existing installs keep working against Assistant Cloud; the hook's options are on its [API reference](/docs/api-reference/integrations/cloud-ai-sdk) and its source is in [`packages/cloud-ai-sdk`](https://github.com/assistant-ui/assistant-ui/tree/main/packages/cloud-ai-sdk).

New work should take one of the two paths below.

## Use the assistant-ui runtime

`useChatRuntime` from `@assistant-ui/ai-sdk` wraps the same AI SDK transport and adds cloud threads, persistence, titles and telemetry through the `cloud` option. It reports everything `useCloudChat` reported, except the per step `finish_reason` and the `disconnected` outcome, which need the AI SDK finish event the runtime does not observe, and it records nine engagement events the hook never did. You can use it headless or with the assistant-ui components.

Follow the [AI SDK + assistant-ui guide](/docs/cloud/ai-sdk-assistant-ui).

## Build on assistant-cloud directly

If you want to keep your own `useChat` wiring, the pieces `useCloudChat` was made of are public in `assistant-cloud`:

- `AssistantCloud` for threads, messages, runs, events, scores and files, with anonymous, JWT and API key authentication
- `createFormattedPersistence` with `aiSDKV6FormatAdapter` from `assistant-cloud/ai-sdk` to store AI SDK messages as the cloud expects them
- `CloudRunReporter` with `extractAISDKRunTelemetry` to turn a finished run's messages into a run report
- `CloudEngagementReporter` for engagement events
- `generateThreadTitle` for automatic thread titles

The [package reference](/docs/api-reference/integrations/assistant-cloud) lists them, and the hook's source is a complete worked example of how they fit together.
