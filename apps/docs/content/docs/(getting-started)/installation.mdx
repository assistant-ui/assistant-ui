All you need to do is ask your coding agent:

<AgentSetupPrompt />

That's it. The agent runs `npx assistant-ui@latest setup`, which opens a guided setup in your browser. You pick a runtime, a backend and the components you want, and the agent installs them and wires them into your project.

It works with Claude Code, Codex, Cursor and any other agent that can run shell commands.

Prefer to do it yourself? Follow the [manual installation](/docs/manual-installation) steps.
