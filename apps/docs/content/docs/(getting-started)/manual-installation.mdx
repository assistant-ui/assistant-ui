<Callout title="Prefer the guided setup?">
  Tell your coding agent to `install and set up assistant-ui`; see [Installation](/docs/installation). Agents already in a setup can follow these steps.

  Coding agents: outside a setup session, `init`, `create` and `add` stop with exit code 2 and point you to `npx assistant-ui@latest setup` (add `--unattended` when nobody will answer). [Manual Setup](#manual-setup) below uses the shadcn CLI and runs anywhere.
</Callout>

## Quick Start

<Steps>
  <Step>

### Initialize assistant-ui

**Add to a project:**

```sh
npx assistant-ui@latest init
```

  </Step>
  <Step>

### Add API key

Create a `.env` file with your API key:

```
OPENAI_API_KEY="sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"
```

Developing locally with a ChatGPT Plus or Pro plan? You can skip the API key and run on your subscription instead; see [ChatGPT Subscription](/docs/guides/chatgpt-subscription).

  </Step>
  <Step>

### Start the app

```sh
npm run dev
```

  </Step>
</Steps>

## Manual Setup

If you prefer not to use the CLI, you can install components manually.

Add the assistant-ui registry to your `components.json` so the shadcn CLI resolves components for your style. Styles whose name starts with `base-` receive Base UI flavored components; all other styles receive the Radix flavored ones. `npx shadcn init` defaults to Base UI styles (for example `base-nova`), so new projects need this style-aware URL for components that compile against that stack.

```json title="components.json"
{
  "registries": {
    "@assistant-ui": "https://r.assistant-ui.com/styles/{style}/{name}.json"
  }
}
```

Existing Radix projects can keep the plain form `https://r.assistant-ui.com/{name}.json` as a fallback (for example `npx shadcn@latest add https://r.assistant-ui.com/thread.json`).

```ts title="/app/api/chat/route.ts" tab="OpenAI"
import { openai } from "@ai-sdk/openai";
import { frontendTools } from "@assistant-ui/ai-sdk";
import {
  convertToModelMessages,
  createUIMessageStreamResponse,
  streamText,
  toUIMessageStream,
} from "ai";

export const maxDuration = 30;

export async function POST(req: Request) {
  const { messages, system, tools } = await req.json();
  const aiSDKTools = frontendTools(tools);
  const result = streamText({
    abortSignal: req.signal,
    model: openai("gpt-6-luna"),
    instructions: system,
    messages: await convertToModelMessages(messages, { tools: aiSDKTools }),
    tools: aiSDKTools,
  });
  return createUIMessageStreamResponse({
    stream: toUIMessageStream({ stream: result.stream }),
  });
}
```

This is the AI SDK v7 form: `instructions` replaces `streamText`'s older `system` option, and `createUIMessageStreamResponse` with `toUIMessageStream` replaces `result.toUIMessageStreamResponse()`. Both older forms still run on v7 but are deprecated; see [AI SDK v7](/docs/runtimes/ai-sdk/v7).

For a local model or any other OpenAI-compatible server, create the provider with its address: `createOpenAI({ baseURL: "http://localhost:11434/v1", apiKey: "unused" })` from `@ai-sdk/openai`, then `model: provider.chat("<model id>")` for servers that only speak Chat Completions. [LLM Gateways](/docs/integrations/gateways) has more.

The `system` prompt and the `tools` schemas in the request body come from the browser, so any caller can change them. Treat both as untrusted input. A system prompt only guides the model, so enforce authorization, argument validation and usage limits in server code, define tools the server executes on the server rather than from the request, and authenticate the route before deploying.

### Use it in your app

The components show tooltips, so wrap your app once in `TooltipProvider`. `shadcn add` installed it with the components:

```tsx title="/app/layout.tsx"
import { TooltipProvider } from "@/components/ui/tooltip";

export default function RootLayout({
  children,
}: {
  children: React.ReactNode;
}) {
  return (
    <html lang="en">
      <body>
        <TooltipProvider>{children}</TooltipProvider>
      </body>
    </html>
  );
}
```

Then render a thread:

<Tabs items={["Thread", "AssistantModal"]}>

```tsx title="/app/page.tsx" tab="Thread"
"use client";

import { AssistantRuntimeProvider } from "@assistant-ui/react";
import { useChatRuntime, AssistantChatTransport } from "@assistant-ui/ai-sdk";
import { ThreadList } from "@/components/assistant-ui/elements/thread-list.aui";
import { Thread } from "@/components/assistant-ui/elements/thread.aui";

export default function MyApp() {
  const runtime = useChatRuntime({
    transport: new AssistantChatTransport({
      api: "/api/chat",
    }),
  });

  return (
    <AssistantRuntimeProvider runtime={runtime}>
      <div>
        <ThreadList />
        <Thread />
      </div>
    </AssistantRuntimeProvider>
  );
}
```
