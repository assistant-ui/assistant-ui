Tools let the model fetch data, call an API, query a database, drive your UI, or ask the user to decide. You declare them once, in a toolkit, and the pages in this section cover the rest.

## How tools fit together

1. **Author** the toolkit in a `"use generative"` file. See [Defining Tools](/docs/tools/defining-tools), which also helps you pick between [backend, frontend, human, provider, and external tools](/docs/tools/defining-tools#tool-kinds).
2. **Register** it on the client with `AuiConfig({ tools: Tools({ toolkit }) })`. See [Registering a toolkit](/docs/tools/defining-tools#registering-a-toolkit-with-tools).
3. **Expose** the same toolkit to the model on your server with `AISDKToolkit`. See [Backend Tools](/docs/tools/backend).
4. **Render** each call as a component, with loading, result, and approval states. See [Tool UI](/docs/tools/tool-ui).

For a tool whose executor needs React state, see [Dynamic Tools](/docs/tools/dynamic-tools).

## Rendering AI output as UI

assistant-ui has a few ways to turn model output into React UI. Pick by **who decides what renders**:

| You want… | Use | The decider |
| --- | --- | --- |
| A custom component for a known tool call (form, picker, chart, status) | [Tool UI](/docs/tools/tool-ui): `render` on a toolkit entry | the **model**, by calling the tool |
| Persistent, out-of-thread state the AI can read and write | [Interactables](/docs/tools/interactables) | the **model and the user**, bidirectionally |
| UI composed from a component vocabulary you ship | [Generative UI](/docs/tools/generative-ui): the `present` tool | the **model**, composing a tree |
| UI pushed by a LangGraph node alongside messages | [LangGraph Generative UI](/docs/runtimes/langgraph/generative-ui): `makeAssistantDataUI` | the **backend or orchestrator** |
| UI composed in OpenUI Lang, rendered by OpenUI's kit (third-party) | [OpenUI](/docs/tools/openui): `@openuidev/assistant-ui` | the **model**, composing a tree |

To compare Markdown, `present`, spec mode, and model-written widgets for one answer, see [Choosing an answer format](/docs/tools/generative-ui-formats).
