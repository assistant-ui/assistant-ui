## Usage

```tsx
import { Line } from "diagrammatic";

<Line labels={["Jan", "Feb", "Mar"]} data={[34, 46, 40]} />;
```

`Line` renders on the server. Pass `data` for one series or `series` for several; `labels` names the points on the x axis.

## Examples

### One series

A single series draws in ink with its last value printed at the end of the line.

<Example file="line/basic"><Basic /></Example>

### Several series

Two or more named series take the categorical palette in order and get a legend. Past four lines, consider [small multiples](/diagrammatic/docs/small-multiples).

<Example file="line/series"><Series /></Example>

### Steps

`step` holds each value until the next one, for quantities that change in discrete jumps: seats, prices, replica counts.

<Example file="line/step"><Step /></Example>

### Regions and annotations

`regions` shades a span of the x axis in index units, and `marks` pins a label to a point. Together they tell the reader why the line moved.

<Example file="line/regions"><Regions /></Example>

### Uncertainty bands

`bands` takes a `lower` and `upper` array per series and draws the range under the line, for forecasts and confidence intervals.

<Example file="line/bands"><Bands /></Example>

### Thresholds

`guides` draws reference lines on either axis: an SLO on the value axis, a deploy on the x axis.

<Example file="line/guides"><Guides /></Example>

### Log scale

`yScale="log"` puts growth that spans decades on one frame. A tick count on log paper counts decades.

<Example file="line/log-scale"><LogScale /></Example>

### Uneven x positions

`xs` places points at numeric x positions instead of evenly, and `xScale="log"` spaces them logarithmically, as a scaling curve needs.

<Example file="line/xs"><Xs /></Example>

### Survival curves

A `step` line with `marks` of `kind: "censor"` is a Kaplan-Meier plot: the ticks mark where observation stopped without an event.

<Example file="line/censor"><Censor /></Example>

## Interaction

These examples wrap the server-rendered chart in `diagrammatic/interactive`. See [Interaction](/diagrammatic/docs/interaction) for the full API.

### Tooltip

The tooltip receives the hovered point's `index` and looks the value up in your data.

<Example file="line/tooltip"><Tooltip /></Example>

### Highlight a series

A controlled `highlight` fades every other series; `highlightOnHover="series"` does the same while the pointer rests on a line.

<Example file="line/highlight"><Highlight /></Example>

### Select a point

`onMarkClick` reports the clicked point's address, and a controlled highlight keeps the selection visible.

<Example file="line/select"><Select /></Example>

### Live data

The chart is a pure function of its props, so streaming data is a state update. This one appends a reading every second, and `data-dg-motion` pulses the latest point while it runs. See [Motion](/diagrammatic/docs/motion).

<Example file="line/live"><Live /></Example>

### Fluid width

`Fit` measures its box and hands the width down, so the frame is laid out again at every width and the type stays at 11px. Resize the window.

<Example file="line/fit"><FitExample /></Example>

## When to use it

- **Use it for** trends, rates, and anything measured on a continuous timeline.
- **Watch out** for more than four lines, which turn to spaghetti; facet into small multiples instead. For a quantity that accumulates, an [area](/diagrammatic/docs/charts/area) reads better.
