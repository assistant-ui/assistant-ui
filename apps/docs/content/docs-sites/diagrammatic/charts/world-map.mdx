## Usage

```tsx
import { WorldMap } from "diagrammatic/world";

<WorldMap values={{ US: 412, DE: 198, IN: 231 }} />;
```

`WorldMap` ships in its own entry, `diagrammatic/world`, because 166 country outlines outweigh every other chart combined; only the pages that draw a map load them. The geometry is pre-projected (Miller) and simplified offline, so the component runs no geo code at render time and stays a server component.

## Examples

### Values by country

`values` is keyed by ISO 3166-1 alpha-2 code. Each country shades from 10% to 95% of the accent by its share of the largest value; a country without a value draws as an outline only.

<Example file="world-map/basic"><Basic /></Example>

### One scale across maps

`max` fixes the top of the ramp, so two maps side by side shade the same value the same way. Without it, each map scales to its own largest value.

<Example file="world-map/shared-scale"><SharedScale /></Example>

### Color and hover style

The ramp is the first categorical token, `--dg-c1`. Every country is a mark with `data-series` set to its code, so CSS can style hover or single countries out.

<Example file="world-map/themed"><Themed /></Example>

## Interaction

Countries are addressed by code: a tooltip reads `datum.series`, and a highlight takes `{ series: "DE" }` or a list of them.

### Tooltip

The figure at the top of this page: `highlightOnHover="series"` plus a `Tooltip` that looks the country's name up in the exported `WORLD` list.

### Highlight a region

A controlled highlight with a list of queries lights up a set of countries and fades the rest.

<Example file="world-map/regions"><Regions /></Example>

### Pick a country

`onMarkClick` reports the clicked country's code.

<Example file="world-map/select"><Select /></Example>

### Zoom

With a function child, `Zoom` hands the map a `view` window and the map redraws through it, so borders keep their hairline width at any magnification. Scroll to zoom, drag to pan, double-click to reset.

<Example file="world-map/zoom"><ZoomExample /></Example>
