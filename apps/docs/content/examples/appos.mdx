## Overview

The Article Assistant is a reading page with a chat that answers questions about one article. It is a plain assistant-ui Vite app that runs as an appOS app. Above, this page embeds it with `<AppOSApp>`: the app runs in a sandboxed frame on its own origin, and this site acts as its shell, answering its model calls through its own backend.

## Features

- **No key in the app**: the app calls `apposModel()`, an AI SDK language model the shell serves. The key stays on the host's server.
- **Local agent loop**: `useChatRuntime` with the AI SDK's `DirectChatTransport` runs the agent in the app's frame. Only model calls leave it.
- **Origin isolation**: the app and the page can't read each other's DOM, storage or cookies. They talk only through `postMessage`.
- **One bundle**: the build packs the app into a single `.wbn` file served from the site.

## How It Works

1. The app's runtime streams through `apposModel()` from `appos-client/ai-sdk`
2. The docs build packs the built app into `public/appos/with-appos.<hash>.wbn` with `pack()` from `appos-host/pack`
3. `<AppOSApp>` loads the bundle into the sandbox and grants the `ai` capability
4. Each model call reaches the page's `ai` service, which posts it to `/api/appos/ai`
5. The route rate-limits the call, picks the model and streams the parts back with `aiResponse()`

### The app's runtime

```ts
// src/appos-runtime.ts
import { useMemo } from "react";
import { DirectChatTransport, ToolLoopAgent } from "ai";
import { useChatRuntime } from "@assistant-ui/react-ai-sdk";
import { apposModel } from "appos-client/ai-sdk";

export function useAppOSRuntime({ instructions }: { instructions: string }) {
  const transport = useMemo(
    () =>
      new DirectChatTransport({
        agent: new ToolLoopAgent({ model: apposModel(), instructions }),
      }),
    [instructions],
  );
  return useChatRuntime({ transport });
}
```

### Embedding it

```tsx
import { AppOSApp, aiGateway } from "appos-host";

<AppOSApp
  src="/appos/with-appos.wbn"
  services={{ ai: aiGateway({ url: "/api/appos/ai" }) }}
  permissions={{ ai: "granted" }}
/>;
```

### The gateway

```ts
// app/api/appos/ai/route.ts
import { openai } from "@ai-sdk/openai";
import { aiResponse } from "appos-host/server";

export async function POST(request: Request) {
  // Rate-limit here: the route is public.
  return aiResponse(await request.json(), {
    model: () => openai("gpt-6-luna"),
    signal: request.signal,
  });
}
```
