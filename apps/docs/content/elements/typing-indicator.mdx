Three dots bouncing in a staggered wave, either bare or sitting inside a rounded bubble. With a runtime you mount it while the assistant reply is pending; standalone you show and hide it yourself.

## Getting started

<RuntimeMode>

`Thread` renders a pending indicator while an assistant message is running and its last part is not streaming text, such as before the first token or after a tool call returns. Pass `TypingIndicator` to its `Indicator` slot to replace the built-in dot.

<Steps>
  <Step>

### Use it in Thread

```tsx title="app/chat/page.tsx"
"use client";

import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { TypingIndicator } from "@/components/assistant-ui/elements/typing-indicator";

const components = { Indicator: TypingIndicator };

export default function Chat() {
  return <Thread components={components} />;
}
```

`Thread` mounts the dots where the assistant's message content will appear.

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

Standalone, `TypingIndicator` takes no data at all; mounting and unmounting it is entirely up to you.

<Steps>
  <Step>

### Drop it in while you wait

```tsx title="app/chat.tsx"
"use client";

import { useState } from "react";
import { TypingIndicator } from "@/components/assistant-ui/elements/typing-indicator";

export function Chat() {
  const [waiting, setWaiting] = useState(false);
  return waiting ? <TypingIndicator /> : null;
}
```

  </Step>
  <Step>

### Choose a variant

```tsx
<TypingIndicator variant="bare" />
```

  </Step>
</Steps>

</StandaloneMode>

## Examples

### Bare dots without the bubble

`variant="bare"` drops the rounded `paper` surface and renders only the three dots, for placement inside your own container.

```tsx
<TypingIndicator variant="bare" className="gap-0.5" />
```

### Restyle the dots

The bubble variant wraps the dots in the shared `paper` surface from `surfaces.tsx`; `className` on either variant only affects the outermost element (the bubble itself for `"bubble"`, the dot row for `"bare"`). The dots' color, size, and bounce timing are fixed and not exposed as props.

```tsx
<TypingIndicator className="px-3 py-2.5" />
```

## API reference

<RuntimeMode>

### Thread slot

| Slot | Type | Description |
|------|------|-------------|
| `components.Indicator` | `ComponentType` | Replaces the pending indicator in a running assistant message. |

</RuntimeMode>

<StandaloneMode>

### TypingIndicator

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `variant` | `"bubble" \| "bare"` | `"bubble"` | `"bubble"` wraps the dots in a rounded surface; `"bare"` renders only the dots. |
| `className` | `string` | | Merged onto the root. |

`role` and `aria-label` are fixed by the component (`"status"` and `"Assistant is typing"`) and are not part of the prop type; every other `div` prop except `children` and `variant` is forwarded.

</StandaloneMode>
