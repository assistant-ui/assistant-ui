---
title: "Thinking indicator"
description: "A live status line that names what the agent is doing right now, with elapsed time."
---

A pulsing dot, a label that fades in fresh every time it changes, and an optional elapsed-time badge. With a runtime you derive the label from whatever the message can tell you and tick the elapsed badge yourself; standalone you pass both in directly.

## Getting started

<RuntimeMode>

The runtime does not hand you a phrase like "Reading the docs"; it hands you the parts that make up the message so far. The most concrete label you can build from that is the name of whatever tool call is still pending, falling back to a plain "Thinking" otherwise.

<Steps>
  <Step>

### Name what is happening from the message parts

```tsx title="components/assistant-ui/elements/assistant-thinking.tsx"
"use client";

import { useAuiState } from "@assistant-ui/react";

function useThinkingLabel() {
  return useAuiState((s) => {
    const pending = s.message.parts.find(
      (part) => part.type === "tool-call" && part.result === undefined,
    );
    return pending?.type === "tool-call"
      ? `Running ${pending.toolName}`
      : "Thinking";
  });
}
```

`Thread` mounts its `Indicator` slot only while the message is running and still needs a pending affordance, so the hook always has a label to show and needs no running check of its own.

  </Step>
  <Step>

### Tick the elapsed badge

```tsx title="components/assistant-ui/elements/assistant-thinking.tsx"
import { useEffect, useState } from "react";
import { ThinkingIndicator } from "@/components/assistant-ui/elements/thinking-indicator";

function useElapsedLabel() {
  const [label, setLabel] = useState<string | undefined>(undefined);
  useEffect(() => {
    const start = Date.now();
    const id = setInterval(() => {
      setLabel(`${Math.round((Date.now() - start) / 1000)}s`);
    }, 1000);
    return () => clearInterval(id);
  }, []);
  return label;
}

export function AssistantThinking() {
  const label = useThinkingLabel();
  const elapsed = useElapsedLabel();
  return <ThinkingIndicator label={label} elapsed={elapsed} />;
}
```

There is no runtime selector for "seconds elapsed so far": `metadata.timing` only finalizes once the message stops streaming, so a live badge needs its own timer, started when the indicator mounts.

  </Step>
  <Step>

### Pass it to Thread

```tsx title="app/chat/page.tsx"
"use client";

import { Thread } from "@/components/assistant-ui/elements/thread.aui";
import { AssistantThinking } from "@/components/assistant-ui/elements/assistant-thinking";

const components = { Indicator: AssistantThinking };

export default function Chat() {
  return <Thread components={components} />;
}
```

The slot replaces Thread's built-in pending dot for a running assistant message.

  </Step>
</Steps>

</RuntimeMode>

<StandaloneMode>

Standalone, `label` is a plain string and `elapsed` is a plain string; the component only handles the fade between labels and the layout.

<Steps>
  <Step>

### Hold the label yourself

```tsx title="app/status.tsx"
"use client";

import { useState } from "react";
import { ThinkingIndicator } from "@/components/assistant-ui/elements/thinking-indicator";

export function Status() {
  const [label, setLabel] = useState("Thinking");
  return <ThinkingIndicator label={label} />;
}
```

Changing `label` replays the shimmer and slide-in on the new text; the component keys its inner label on the string itself.

  </Step>
  <Step>

### Add elapsed time

```tsx
<ThinkingIndicator label={label} elapsed="12s" />
```

Omit `elapsed` entirely to hide the badge; passing an empty string still renders it.

  </Step>
</Steps>

</StandaloneMode>

## Examples

### Reacting to a pending tool call

The label only needs to change; the fade-in is automatic because the element keys its shimmer span on the label text.

```tsx
const pending = message.parts.find(
  (part) => part.type === "tool-call" && part.result === undefined,
);
const label = pending?.type === "tool-call" ? `Running ${pending.toolName}` : "Thinking";
```

### Restyle the status line

The dot is fixed to `bg-blue-500`; the label uses `ShimmerLabel` and the elapsed badge uses the shared `mono` token from `surfaces.tsx`. `className` merges onto the root, which starts as `text-muted-foreground flex items-center gap-2.5 text-sm`.

```tsx
<ThinkingIndicator label={label} elapsed={elapsed} className="gap-1.5 text-xs" />
```

## API reference

<RuntimeMode>

### Message state

| Selector | Type | Description |
|----------|------|-------------|
| `s.message.status` | `MessageStatus \| undefined` | `status.type === "running"` while the assistant is still producing this message. |
| `s.message.parts` | `readonly PartState[]` | Scan for a `"tool-call"` part with no `result` yet to name what is running; an empty array with the message still running means nothing has arrived at all. |

</RuntimeMode>

<StandaloneMode>

### ThinkingIndicator

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `label` | `string` | required | Status text; changing it replays the fade-in. |
| `elapsed` | `string \| undefined` | | Preformatted elapsed time shown after the label. Omit to hide the badge. |
| `className` | `string` | | Merged onto the root. |

All other `div` props except `children` are forwarded to the root.

</StandaloneMode>
