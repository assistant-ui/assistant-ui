## Usage

```tsx

  return (
    <label className="flex items-center gap-2 text-sm">
      <Switch defaultChecked />
      Streaming
    </label>
  );
}
```

## Examples

### Sizes and disabled

`default` measures 32×18 and `sm` 24×14. A disabled switch keeps its state visible at half opacity.
