Run an action to watch the cursor click a real task control. You can also operate each control with your mouse or keyboard.

## Installation

<KitInstall name="agent-cursor" />

The component depends on React. Base UI and Radix variants have the same props and markup.

## Usage

```tsx
import { useRef, useState } from "react";
import { AgentCursor } from "@/components/ui/agent-cursor";

export function TaskControl() {
  const button = useRef<HTMLButtonElement>(null);
  const [completed, setCompleted] = useState(false);

  return (
    <>
      <button ref={button} onClick={() => setCompleted(!completed)}>
        {completed ? "Reopen task" : "Complete task"}
      </button>
      <AgentCursor target={button} phase="idle" label="Agent" />
    </>
  );
}
```

`target` accepts an element, an element ref, or `{ x, y }` in viewport pixels. Element targets use the center of their bounding rectangle and update on scroll, resize, and element resizing. Render the cursor outside transformed ancestors so its fixed positioning stays relative to the viewport.

Your application performs the action. Move the cursor to a target, set `phase="clicking"` when the action runs, then return to `idle`. The cursor itself never clicks, focuses, or intercepts an element.

## Accessibility and motion

The pointer is decorative and always hidden from assistive technology. Announce progress and results through the application's status region, and retain normal keyboard access to every target. The [website agent bundle](/components/bundles/website-use-agent) demonstrates this pattern with working task controls.

`prefers-reduced-motion` disables movement interpolation and the click bounce. A static ring still confirms the clicking phase.
