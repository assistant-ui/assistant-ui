## Installation

Button is part of the assistant-ui kit. Registry items that need it install it automatically as a dependency; to use it on its own, copy the source file into `components/ui/`.

## Usage

```tsx
import { Button } from "@/components/ui/button";

export function Example() {
  return <Button variant="outline">Read the docs</Button>;
}
```

## Variants and sizes

`variant` takes `default`, `outline`, `secondary`, `ghost`, and `destructive`. `size` takes `xs`, `sm`, `default`, `lg`, and the square `icon` sizes for icon-only buttons. The default height is 32px; `sm` is the 28px header control.
