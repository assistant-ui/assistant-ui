## Installation

Avatar is part of the assistant-ui kit. Registry items that need it install it automatically as a dependency; to use it on its own, copy the source file into `components/ui/`.

## Usage

```tsx
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar";

export function Example() {
  return (
    <Avatar>
      <AvatarImage src="/avatar.png" alt="Ada" />
      <AvatarFallback>AD</AvatarFallback>
    </Avatar>
  );
}
```

## Groups

`AvatarGroup` overlaps its children and `AvatarGroupCount` closes the stack with an overflow count. `AvatarBadge` pins a status marker to the rim.
