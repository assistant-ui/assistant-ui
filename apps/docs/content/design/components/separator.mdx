## Installation

Separator is part of the assistant-ui kit. Registry items that need it install it automatically as a dependency; to use it on its own, copy the source file into `components/ui/`.

## Usage

```tsx
import { Separator } from "@/components/ui/separator";

export function Example() {
  return (
    <div className="flex h-5 items-center gap-3 text-sm">
      <span>Docs</span>
      <Separator orientation="vertical" />
      <span>Elements</span>
    </div>
  );
}
```
