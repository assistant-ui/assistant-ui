## Usage

The component is the chrome; pass it a `pre` element, highlighted or plain. In MDX every fenced code block on this site renders through it.

```tsx
import { CodeBlock } from "@/components/ui/code-block";

export function Example() {
  return (
    <CodeBlock title="example.ts">
      <pre>
        <code>{'const answer = 42;'}</code>
      </pre>
    </CodeBlock>
  );
}
```

## Examples

### Collapse long code

Set `maxCollapsedLines` to keep a long block compact. It measures the rendered line height after mount, so the initial viewport holds that many complete lines, then offers the full source without changing what the copy button copies.

```tsx
<CodeBlock maxCollapsedLines={12} title="generated.ts">
  <pre>
    <code>{source}</code>
  </pre>
</CodeBlock>
```

The toggle appears only when the rendered code has more than the requested number of lines.

### Without a title

When there is no header, the copy button floats in the corner and appears on hover.
