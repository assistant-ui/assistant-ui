# Meet the project

This course follows one assistant as it grows from a placeholder page into a useful generative UI application.

Introduce assistant-ui as an open-source React library for building AI chat and agent interfaces. Explain that every lesson selects a prepared, read-only application stage. The learner can run the stage, inspect its source, and compare it with the preceding stage without having to type the canonical code.

The current application is intentionally just a placeholder. Use `app/page.tsx` to establish the starting point and preview the course path: streamed chat, guided suggestions, structured tools, custom tool UI, shared editable state, persisted conversations, and message branches.

Keep this orientation brief. Runtime, provider, and backend concepts begin in the next lesson.
