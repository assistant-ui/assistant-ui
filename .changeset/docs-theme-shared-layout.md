feat: `theme: assistantUi()` with `@assistant-ui/docs-theme/styles.css` now gives the assistant-ui docs look on every Farming Labs framework, without a custom layout. The theme renders the header across the top with search, `nav.links` and the theme toggle, a skip link, previous/next arrows and a page actions menu beside the title (Copy page, View as Markdown, Open in Claude or Codex, Copy MCP server URL, each with a one-line description), table of contents actions, a flat sidebar and no breadcrumb; site configuration overrides any of these defaults. The stylesheet applies only to layouts marked `data-fd-theme="assistant-ui"`. Requires Farming Labs Docs and Theme 0.2.141. `createDocsLayout` keeps its own header and page controls, now built on Fumadocs' framework-neutral `Link` and `usePathname`, which adds `fumadocs-core` as a peer. `assistantUiDefaults` exports the theme's configuration defaults. The theme also brings the assistant-ui MDX components (numbered code blocks, `CodeGroup`, `Callout` and blockquotes, `Tabs`, `Steps`, `Cards`, `Files`, linkable headings, tables, `Kbd`, `Code`, `ThemeImage`) and the Catppuccin code themes, styled by the same stylesheet; `@assistant-ui/docs-theme/mdx` exports them.
